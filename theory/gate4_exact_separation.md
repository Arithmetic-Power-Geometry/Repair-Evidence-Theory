# Gate 4 — Exact Separation Construction

Status: mathematical construction under novelty audit.

## 1. Why a naive counterexample is insufficient

A trivial example can always choose an untested input on which two test-passing patches disagree. That only restates the classical incompleteness of finite testing.

RCR needs a sharper construction:

1. the supplied tests all pass;
2. structural coverage can be maximal;
3. mutation adequacy relative to the chosen mutant set can be maximal;
4. nevertheless two admissible repairs are indistinguishable by the assessor evidence;
5. those repairs lie on opposite sides of a declared semantic repair claim.

The contribution cannot be “testing is incomplete.” It must expose the **non-implication between conventional adequacy measurements and resolution of a declared repair claim over a repair universe**.

---

# 2. Smallest exact construction

Consider a defective function intended to satisfy a contract over an input domain (X).

Let

[
X={0,1,2}.
]

Declared semantic contract:

[
S(x)=x.
]

Buggy program:

[
P_0(x)=0.
]

Available regression/test evidence:

[
T={(0,0),(1,1)}.
]

Consider two admissible repairs:

[
r_+(x)=x
]

and

[
r_-(x)=
\begin{cases}
x,&x\in\{0,1\},\\
0,&x=2.
\end{cases}
]

Both satisfy all supplied tests:

[
Obs_T(r_+)=Obs_T(r_-)=\{0,1\}.
]

But for semantic claim

[
c_S(r)=1
iff
orall x\in X, r(x)=S(x),
]

we have

[
c_S(r_+)=1,qquad c_S(r_-)=0.
]

Therefore

[
r_+\sim_T r_-
quad	ext{and}quad
c_S(r_+)\ne c_S(r_-),
]

so (T) does not resolve (c_S).

This example is intentionally elementary. It is a witness, not a novelty claim.

---

# 3. Infinite finite-domain family

Let (X_n=\{1,\ldots,n\}), (n\ge2), and let (S:X_n\to Y) be the declared intended behavior.

For any strict test subset

[
T\subsetneq X_n,
]

choose

[
z\in X_n\setminus T.
]

Define

[
r_+(x)=S(x)
]

and choose (y'\ne S(z)), defining

[
r_-(x)=
\begin{cases}
S(x),&x\ne z,\\
y',&x=z.
\end{cases}
]

Then

[
r_+\sim_T r_-,
]

while for the global semantic claim

[
c_S(r)=1\iff \forall x\in X_n, r(x)=S(x),
]

[
c_S(r_+)\ne c_S(r_-).
]

Thus any strict finite-domain test subset fails to resolve unrestricted pointwise semantic correctness whenever the repair universe contains both repairs.

Again, this is essentially a completeness observation and is not claimed novel.

---

# 4. Stronger repair-relative formulation

The useful object is not input coverage but the interaction among:

[
(T,\mathcal R,c).
]

Define a test observation map

[
O_T:\mathcal R\to\Omega_T.
]

Define the partition

[
\Pi_T=\mathcal R/{\sim_T}.
]

Define the claim partition

[
\Pi_c=\{c^{-1}(v):v\in\mathcal C\}.
]

Then RCR holds exactly when

[
\Pi_T\preceq\Pi_c,
]

i.e. every evidence cell lies wholly inside one claim cell.

This partition-refinement statement is generic mathematics. The APR contribution must come from how (mathcal R), (O_T), and (c) are operationalized and measured.

---

# 5. Adequacy-separation construction

Suppose a conventional adequacy score

[
A(T,P)
]

depends only on execution properties observed over the tested inputs (for example statement/branch coverage), not on unobserved semantic distinctions between repairs.

Construct (r_+) and (r_-) so that every executable statement/branch in each candidate is exercised by (T), while they differ on a data value or predicate outcome outside (T).

Then it is possible to have

[
A(T,r_+)=A(T,r_-)=1
]

while

[
RCR(\mathcal R,T,c_S)=0.
]

For structural coverage this is straightforward because executing a branch is not equivalent to exhaustively checking all semantic values processed by that branch.

### Candidate proposition: Coverage–Resolution Non-Implication

For structural coverage criteria that quantify executed program structure rather than semantic completeness over the repair universe, maximal structural coverage does not in general imply RCR for a stronger semantic claim.

**Novelty status:** likely a specialization of long-known limitations of coverage criteria. Do not market this proposition alone as a breakthrough.

---

# 6. Mutation adequacy is harder

A claim of “100% mutation score yet unresolved correctness” must specify the mutation operator set (M).

Mutation adequacy means the tests distinguish the program from all non-equivalent mutants *generated by (M)*. It does not quantify all admissible repairs in (mathcal R).

Therefore a potential separation exists whenever

[
M(P)\subsetneq\mathcal R
]

and an unresolved cross-claim repair lies outside the generated mutant family.

This gives:

### Candidate proposition: Generator-Relative Adequacy

Perfect discrimination over a generated surrogate set (G\subseteq\mathcal R) implies RCR over (mathcal R) only if the surrogate set is claim-complete in the relevant sense.

Define (G) to be **claim-boundary complete** for ((E,c,\mathcal R)) if every evidence cell that crosses a claim boundary contains a detectable representative of that crossing in (G).

Without such completeness, perfect performance on (G) cannot certify RCR on (mathcal R).

This is more promising than the basic coverage result because it applies not only to mutation testing but also:
- sampled APR candidate corpora;
- generated adversarial patches;
- LLM-generated validation sets;
- benchmark subsets;
- learned surrogate repair spaces.

---

# 7. General surrogate-resolution theorem candidate

Let (\mathcal R) be the target repair universe and (G\subseteq\mathcal R) the subset actually evaluated.

Suppose an assessor establishes claim homogeneity for every evidence class intersected with (G):

[
\forall C\in\Pi_E,quad
|c(C\cap G)|\le1.
]

This does **not** imply

[
\forall C\in\Pi_E,quad |c(C)|\le1
]

unless (G) satisfies an additional coverage condition over claim boundaries.

A sufficient condition is:

[
\forall C\in\Pi_E,quad
|c(C)|>1
\Rightarrow
|c(C\cap G)|>1.
]

Call this condition provisionally **claim-boundary completeness**.

Under claim-boundary completeness,

[
RCR(G,E,c)\iff RCR(\mathcal R,E,c).
]

The forward direction follows because any unresolved full-universe cell must expose both claim values in (G); the reverse direction is immediate by restriction.

This is the first Gate-4 statement worth a serious novelty audit.

---

# 8. Why this may matter empirically

APR/APCA studies cannot usually enumerate the full meaningful repair universe. They evaluate:
- tool-generated candidate patches;
- benchmark corpora;
- sampled plausible patches;
- mutants;
- LLM-generated alternatives.

Thus empirical evidence that an assessor separates correct/incorrect patches in a sampled/generated set does not automatically establish that its evidence resolves correctness over the intended repair universe.

The missing assumption is whether the evaluated surrogate is sufficiently representative of **claim-boundary crossings inside evidence-equivalence classes**.

This turns the problem from generic “tests are incomplete” into a three-way issue:

[
\boxed{\text{evidence} \times \text{repair universe} \times \text{evaluation surrogate}.}
]

---

# 9. Gate 4 verdict

## Killed as headline novelty
- finite tests cannot prove arbitrary semantic correctness;
- 100% structural coverage does not imply correctness;
- test-passing patches can overfit.

## Surviving candidate
**Claim-boundary completeness of evaluated repair surrogates**, and its necessity/sufficiency for transferring repair-claim resolution conclusions from a sampled/generated candidate set to a declared target repair universe.

## Next attack
Compare this exact construct against:
1. mutation-testing coupling effect / competent programmer hypothesis;
2. subsuming mutants and mutant representativeness;
3. test-set completeness;
4. PAC/VC generalization and sample representativeness;
5. adversarial robustness / coverage;
6. benchmark representativeness in APR/APCA;
7. metamorphic testing;
8. specification completeness.

If an existing construct already gives the same boundary-preservation condition, rename/reduce or kill it before implementation.
